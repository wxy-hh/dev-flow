# 断局速查

## 用神速查

| 事项 | 用神 | 辅助 |
|------|------|------|
| 求财 | 生门、戊 | 看生门落宫旺衰 |
| 事业 | 开门、值符 | 日干落宫为自己 |
| 考试 | 景门、天辅 | 丁奇落宫 |
| 婚姻(男问) | 六合、乙为己庚为她 | 乙庚关系 |
| 婚姻(女问) | 六合、庚为己乙为他 | 乙庚关系 |
| 疾病 | 天芮、死门 | 天心为医 |
| 出行 | 值使门 | 看所去方位宫 |
| 官司 | 开门(我)、惊门(对方) | 值符为官方 |
| 寻人寻物 | 六合 | 落宫为方位 |

## 吉凶速判

### 最吉组合
- 三奇(乙丙丁) + 吉门(开休生) + 吉星(冲辅心任) + 吉神(值符太阴九天)

### 最凶组合
- 六仪(庚辛) + 凶门(死惊伤) + 凶星(蓬芮柱英) + 凶神(腾蛇白虎玄武)

### 常见吉格
| 格局 | 条件 | 含义 |
|------|------|------|
| 天遁 | 丙+壬+生门 | 大吉 |
| 地遁 | 乙+己+开门 | 大吉 |
| 人遁 | 丁+癸+休门 | 大吉 |
| 青龙转光 | 丁+戊 | 吉 |
| 飞鸟跌穴 | 丙+戊 | 大吉 |

### 常见凶格
| 格局 | 条件 | 含义 |
|------|------|------|
| 大格 | 庚+癸 或 庚+壬 | 大凶 |
| 小格 | 庚+己 | 凶 |
| 刑格 | 庚+庚(伏吟) | 白虎猖狂 |
| 飞宫格 | 庚+丙 | 凶 |
| 悖格 | 辛+壬 或 壬+辛 | 凶 |
| 上格 | 庚+戊 | 值符飞宫 |

### 特殊状态
| 状态 | 含义 |
|------|------|
| 伏吟 | 天盘=地盘，事不动 |
| 反吟 | 星门到对冲宫，反复 |
| 空亡 | 用神落空，事难成 |
| 入墓 | 用神入墓库，被困 |
| 门迫 | 门受宫克，受压制 |

## 九星一句话象意
- 天蓬：盗贼暗昧
- 天芮：疾病小人
- 天冲：果断行动
- 天辅：文书贵人
- 天禽：稳重中正
- 天心：医药领导
- 天柱：破败口舌
- 天任：信用稳固
- 天英：血光是非

## 八门一句话象意
- 休门：贵人安逸 → 利求见、休养
- 生门：财运生意 → 利求财、置业
- 伤门：受伤竞争 → 利打猎、竞技
- 杜门：堵塞隐藏 → 利躲避、防守
- 景门：文书考试 → 利考试、访友
- 死门：死亡不动 → 利吊丧、钓鱼
- 惊门：惊恐口舌 → 利诉讼(对方凶)
- 开门：开创事业 → 利工作、出行

## 八神一句话象意
- 值符：贵人正义
- 腾蛇：惊恐怪异
- 太阴：暗助女贵
- 六合：合作婚姻
- 勾陈/白虎：凶险血光
- 朱雀/玄武：口舌小人
- 九地：柔顺守旧
- 九天：刚健上升

## 断局五步法

1. **定用神**：查上表确定用神
2. **看落宫**：用神在哪宫？旺还是衰？空不空？
3. **看格局**：天盘+地盘组合是吉格还是凶格？
4. **看门星神**：宫内的门、星、神各是什么？吉多还是凶多？
5. **看生克**：用神宫与日干宫是相生还是相克？→ 得出结论
