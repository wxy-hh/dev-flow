## 八神排列顺序

### 阳遁（顺时针排）
值符→腾蛇→太阴→六合→勾陈→朱雀→九地→九天

### 阴遁（逆时针排）
值符→腾蛇→太阴→六合→白虎→玄武→九地→九天

> 八神从值符（大值符天盘星）所在宫位开始，阳遁顺排，阴遁逆排。

## 六甲隐仪表（旬首速查）

| 旬首 | 隐于 | 旬内天干 | 旬空 |
|------|------|---------|------|
| 甲子 | 戊 | 甲乙丙丁戊己庚辛壬癸 + 子丑寅卯辰巳午未申酉 | 戌亥空 |
| 甲戌 | 己 | 甲乙丙丁戊己庚辛壬癸 + 戌亥子丑寅卯辰巳午未 | 申酉空 |
| 甲申 | 庚 | 甲乙丙丁戊己庚辛壬癸 + 申酉戌亥子丑寅卯辰巳 | 午未空 |

| 甲辰 | 壬 | 甲乙丙丁戊己庚辛壬癸 + 辰巳午未申酉戌亥子丑 | 寅卯空 |
| 甲寅 | 癸 | 甲乙丙丁戊己庚辛壬癸 + 寅卯辰巳午未申酉戌亥 | 子丑空 |

### 快速查旬首方法
根据时柱地支判断属于哪一旬：
- 子丑寅卯辰巳午未申酉 → 甲子旬（隐戊，戌亥空）
- 戌亥子丑寅卯辰巳午未 → 甲戌旬（隐己，申酉空）
- 申酉戌亥子丑寅卯辰巳 → 甲申旬（隐庚，午未空）
- 午未申酉戌亥子丑寅卯 → 甲午旬（隐辛，辰巳空）
- 辰巳午未申酉戌亥子丑 → 甲辰旬（隐壬，寅卯空）
- 寅卯辰巳午未申酉戌亥 → 甲寅旬（隐癸，子丑空）

**更简单的方法**：用时柱天干地支直接查：

|------|------|------|------|
| 甲子~癸酉 | 甲子 | 戊 | 戌亥 |
| 甲戌~癸未 | 甲戌 | 己 | 申酉 |
| 甲申~癸巳 | 甲申 | 庚 | 午未 |
| 甲午~癸卯 | 甲午 | 辛 | 辰巳 |
| 甲辰~癸丑 | 甲辰 | 壬 | 寅卯 |
| 甲寅~癸亥 | 甲寅 | 癸 | 子丑 |
