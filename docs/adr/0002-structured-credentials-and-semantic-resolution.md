# 可信回答采用宿主结构化凭证与语义解析

---
status: accepted
---

ADR-0001 确立了可信回答按事件顺序绑定：同宿主、呈现之后、唯一且未消费。其实现把"来源验证"误读为"文本逐字相等"：宿主捕获的表单选择被降级成纯文本后，又被逐字比较拒绝，导致用户在表单中选中后仍被迫重答（2026-08 m-level-issue-8499 三次确认即为此症状）。

本决策明确两点：宿主记录的表单选中（AskUserQuestion 结构化选择、原生 MCP 表单）本身就是可信回答，直接按所选选项落账，不经过智能体转述验证；文本消息按受控语义等价解析到选项（标签归一化、确认语义词、登记短语），不再与任何转述文本逐字比较。ADR-0001 禁止的"option id 捷径"是指智能体声称的选择，不是宿主记录的选择。回答落账后，决定依据变化时重新呈现变化并请求一致性确认（依据偏移提醒），而非让用户重答。

_Considered Options_: 保持逐字比较（体验分裂且是本次故障根因）；自由自然语言理解（违反"不引入模糊猜测"红线）。两者均被拒绝。
