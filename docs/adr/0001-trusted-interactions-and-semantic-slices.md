# ADR-0001：可信回答采用事件顺序，治理证据采用语义切片

## Context

宿主消息可能跨回合、跨宿主或重复到达；项目配置和审查结果也不应因为无关命令或投影变化而整体失效。

## Decision

Core 为每个 interaction 记录 presentation 标识，并只接受同一宿主、呈现之后、唯一且未消费的回答。新的 Trace 与 Review 依据按其引用的命令、角色和执行语义切片计算；旧快照缺少切片信息时保守地按整体配置哈希判断。

## Consequences

回答不能靠 option id 或事件重建绕过来源约束；配置高影响变化需要显式重分类。语义切片提高了无关变化的稳定性，但要求快照保留引用身份，兼容旧快照时会更保守。
